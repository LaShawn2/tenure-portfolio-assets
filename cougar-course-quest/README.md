# Cougar Course Quest — Full Standalone Web Version

This folder is ready for GitHub Pages. Upload the entire folder to your repository and open `index.html` through the GitHub Pages URL.

## Full game mechanics retained
- 40-question pool
- 15 correct answers required to win
- Random 1–3 space movement
- Reward spaces
- Trapper challenge
- Lost Woods challenge
- Shortcut to the Cougar Den
- Office Hours challenge
- Space 22 completion gate
- Hint / Game Syllabus Guide
- Browser progress saving with localStorage
- Downloadable completion receipt

## Blackboard note
This version does not use SCORM and does not automatically send a grade or completion status to Blackboard. Link to the GitHub Pages URL from Blackboard Ultra.

## Completion screen
The final screen shows **COURSE QUEST COMPLETE**, provides the completion code and receipt ID, lets the student download a receipt, and includes a **Replay Game** button.

## Image optimization
Large PNGs were checked and recompressed where a smaller lossless file could be produced without changing pixel dimensions. Files that were already efficiently compressed were left unchanged.
