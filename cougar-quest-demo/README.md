# Cougar Course Quest – Tenure Portfolio Demo

Standalone HTML5 version for GitHub Pages and Blackboard Ultra web linking.

## Demo route

1 → 4 → 7 (Trap) → 15 (Shortcut) → 23 (Cougar Den)

The demonstration uses five cards maximum: three course questions, one Trap challenge, and one Shortcut challenge. Movement is deterministic. Incorrect responses retry the same card and retain access to the hint.

## Publish with GitHub Pages

Upload the contents of this folder to a GitHub repository or subfolder that is published by GitHub Pages. `index.html` is the launch page.

No SCORM or LMS completion API is used in this build. Progress is stored only in the reviewer's browser via localStorage.
